# 🚀 Docker Multi-Container Socket Programming with MySQL

A Docker-based distributed system consisting of MySQL, Python TCP socket servers, and C TCP socket servers communicating through a shared Docker network.

## 1. Introduction

Docker is a platform that enables developers to package applications and their dependencies into containers. Containers provide a lightweight and efficient environment that allows applications to run consistently across different systems.

In this project, Docker technology is used to deploy multiple containers consisting of a MySQL database, Python socket servers, and C socket servers. All containers are connected through the same Docker network, allowing them to communicate efficiently.

The project demonstrates the concepts of:

* Socket Programming
* Docker Containerization
* Docker Networking
* Database Integration

Python and C programming languages are used to implement TCP socket servers, while MySQL is used to store and manage data generated by the servers.

The system is designed to update user points periodically and store the latest timestamp in the database.

# 2. Objectives

The objectives of this project are:

1. Deploy multiple Docker containers using Docker Compose.

4. Integrate a MySQL database with server applications.
5. Update database records automatically every 30 seconds.
6. Store user points and timestamps in a centralized database.
7. Gain practical knowledge of Docker containerization technology.

# 4. System Architecture

## Python Server Containers

* Python Server 1

* Python Server 3

## C Server Containers

* C Server 1
* C Server 2
* C Server 3

All containers are connected through the Docker network:

```text
project_network
```

## Communication Flow

1. Python servers connect to MySQL database.
2. Each Python server updates its own user record every 30 seconds.
3. MySQL stores user points and timestamps.
4. C servers provide TCP socket services.
5. Docker network allows communication between all containers.

# 6. Docker Compose Configuration

Docker Compose is used to:

* Build containers
* Create Docker network
* Map ports
* Start services automatically
* Manage dependencies

## docker-compose.yml

```yaml
version: '3'

services:

  mysql_db:
    image: mysql:5.7
    container_name: mysql_db
    restart: always

    environment:
      MYSQL_ROOT_PASSWORD: root
      TZ: Asia/Kuala_Lumpur

    ports:
      - "3306:3306"

    volumes:
      - ./db/init.sql:/docker-entrypoint-initdb.d/init.sql

    networks:
      - project_network

  python_server1:
    build: ./python_server1

    environment:
      TZ: Asia/Kuala_Lumpur

    ports:
      - "5001:5001"

    depends_on:
      - mysql_db

    networks:
      - project_network

  python_server2:
    build: ./python_server2

    environment:
      TZ: Europe/London

    ports:
      - "5002:5002"

    depends_on:
      - mysql_db

    networks:
      - project_network

  python_server3:
    build: ./python_server3

    environment:
      TZ: Europe/Berlin

    ports:
      - "5003:5003"

    depends_on:
      - mysql_db

    networks:
      - project_network

  c_server1:
    build: ./c_server1

    ports:
      - "6001:6001"

    networks:
      - project_network

  c_server2:
    build: ./c_server2

    ports:
      - "6002:6002"

    networks:
      - project_network

  c_server3:
    build: ./c_server3

    ports:
      - "6003:6003"

    networks:
      - project_network

networks:
  project_network:
```

# 11. Problems Faced

| --------------------------------------- | ----------------------------------------------- |

| Containers cannot communicate           | Connected all containers to same Docker network |
| Docker Compose file error               | Corrected YAML indentation                      |
| C client cannot connect using localhost | Used Docker hostname                            |
| Timezone mismatch                       | Configured timezone settings                    |
